Claude 中文（静默）

magpie-claude-zh-silent

为第三方 Gateway 模式的原版 Claude Desktop 加载官方中文界面。不弹 DevTools、不弹文件选择框、不需要把 Claude 切到前台。语言目录由 magpie-claude-zh 提供，请先安装并保留它。

语言

怎么用

  1. 在本页保存设置后，让 magpie 调用工具 claude_zh_silent_launch（说「用静默方式启动 Claude」即可），或用桌面快捷方式「Claude (中文)」。
  2. Claude 打开后几秒内界面变为中文。全程没有窗口弹出。

注意

  • 从开始菜单或原图标启动的 Claude 没有调试端口，本插件不会处理它；那种情况下由 magpie-claude-zh 的 DevTools 方式接管（会弹窗）。想完全不弹窗，就只用上面的启动方式。
  • 调试端口只绑定本机回环地址。它允许本机上的其他进程控制 Claude 界面，这是此方案的固有代价。
  • 注入只在内存中生效，重启 Claude 即恢复英文。
